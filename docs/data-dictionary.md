# Data Dictionary

- `agent_registry.csv`: deterministic agent registry.
- `tool_registry.csv`: governed tool inventory.
- `enterprise_tasks.csv`: synthetic enterprise tasks.
- `probability_scenarios.csv`: scenario assumptions.
- `task_routing_decisions.csv`: agent routing decisions.
- `tool_permission_decisions.csv`: tool access decisions.
- `agent_handoff_history.csv`: multi-agent handoff history.
- `conflict_resolution_decisions.csv`: arbitration outcomes.
- `final_agent_decisions.csv`: final task decisions.
- `human_approval_queue.csv`: human review queue.
- `agent_action_history.csv`: audit trail.
