# Red-Team Scenario Design

V0.2 adds deterministic adversarial scenarios for multi-agent governance.

Covered attacks:
- prompt injection tool override
- hidden sensitive data request
- cross-domain tool abuse
- approval bypass attempt
- tool result poisoning
- memory contamination
- confidence without evidence
- excessive autonomy escalation
- unsafe irreversible action

Each scenario has expected detection, expected policy result, expected final decision, severity, and evidence. Results are written to `data/red_team/` and summarized in `red_team_scorecard`.
