# Data Flow

1. Generate domain data.
2. Generate enterprise tasks.
3. Generate probability scenarios.
4. Build agent and tool registries.
5. Route tasks.
6. Evaluate tool policies.
7. Generate handoffs and conflicts.
8. Run probability simulations.
9. Apply safety gates and final decisions.
10. Create approvals, memory, audit logs, briefings, scorecards, and DuckDB tables.
